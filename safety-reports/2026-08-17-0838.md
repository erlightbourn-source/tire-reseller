**Audited commit (main HEAD):** `2fe7254`

## 0. Reliability incident found + fixed (read this first)

This routine's own dev.log tombstone showed **8 consecutive dead runs** — every
scheduled fire since 2026-07-16 (7/20, 7/23, 7/27, 7/30, 8/3, 8/6, 8/10, 8/13)
logged a `RUN-START` breadcrumb and nothing else: no report, no PR, no
completion line. Root cause, confirmed against `openclaw cron runs` history:
the run was dispatching the three project passes via background
spawn-then-yield and ending its own turn immediately ("I'll compile the run
report once they finish"). A cron-triggered turn never gets woken back up to
collect that — it just gets marked `finished` with a token count, and the
spawned children (if they ran at all) had nothing to commit/report/log their
work. This is the exact `daily-market-brief` hang pattern from 2026-07-14
(see FLEET-MEMORY), which was already fixed there via a HOST EXECUTION RULE
(do the work inline, in-turn) — that hardening was never applied to this
routine. **Fixed this run: did the TireTrader pass entirely inline, no
spawn/yield.** Also splitting the consolidated 3-project cron into 3
separate scheduled jobs so a budget/context exhaustion in one project can't
silently swallow the other two — see the standalone infra note sent to
Evan; this was already recommended in `memory/tiretrader-routine-dead-runs-2026-08.md`
on 8/3 after a 2-run repeat and never actioned before it repeated 8 times.

**Side effect of the outage:** 3 open safety-report PRs (#13 7/9, #15 7/13,
#16 7/16) sat unreviewed for 31–39 days and bit-rotted (their branches predate
the 7/19 founding-seller Prisma migration — merging them as-is would have
*reverted* shipped schema/outreach work). One of their proposals duplicated
itself into today's pass before I caught it (see below). **Closed #13, #15,
#16** with an explanatory comment — they're superseded, not lost: the
detectOffPlatform test-lock they carried already landed on main via a later
commit, and the still-relevant enumeration-safety proposal from #13 is
re-implemented fresh below instead of merged from the stale branch.
